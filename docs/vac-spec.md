# VAC 文字同步規格

本文件供下一輪圖卡更新使用；本次未生成新版圖片。

|步驟|內容|
|---|---|
|01 任務理解|確認股票代號、上市市場與單一查詢日期|
|02 行情取得|taux-io/twse-mcp；TWSE 官方完整日行情分列|
|03 資料驗證|精確代號、日期、OHLC、缺值；不得用 bid/ask 補成交價|
|04 指標計算|漲跌、振幅、MA5/20；量比只用同口徑官方日股數|
|05 價量分析|使用 ai-stock-skill 0.1.0，描述價量與均線位置|
|06 綜合判讀|同交易日才能比較，分開事實與推論|
|07 結果解釋|附來源、交易日、擷取時間、單位與限制|
|08 QA 交付|真實 API、模擬與未驗證分列；交付報告與原件|

狀態文字：原地端盤後核心驗證通過；本輪離線原件核對通過；盤中、雲端及新機待驗證。
