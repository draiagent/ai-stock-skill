# 企業內部使用

本 Skill 適合台股資料查詢與研究流程示範。一般行政、ISO 或營運管理需另建資料來源及分析規則，不能直接宣稱本 Skill 能完成。

|角色|責任|
|---|---|
|使用者|提供股票、日期及需求；查看限制|
|維護者|管理版本、網路、依賴與變更測試|
|覆核者|核對同日、量的口徑及推論依據|

導入順序：隔離環境安裝 → 跑合成測試 → 單股／雙股實測 → 檢查輸出 → 保存版本與驗收。外部行情僅傳股票代號與日期，勿把客戶持倉或帳戶資料塞進請求。

系統沒有付費模型 API；宿主 Agent、人工覆核、維護與未來雲端成本仍須分開計算。可記錄每次耗時、資料完整率及人工修正次數。本版尚無企業 SLA、排程或權限管理。

對外提供資料前另確認資料使用條件；本版不提供投資決策授權或自動交易能力。
