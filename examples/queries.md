# 操作案例

以下是操作指令與預期行為，並非本輪即時報價。

|輸入|應觀察的輸出|
|---|---|
|`./run.ps1 '查台積電 2330'`|單股日行情、MIS 快照、均線、來源時間|
|`./run.ps1 '比較台積電 2330、聯發科 2454'`|兩股同日比較；缺同日資料時拒絕比較|
|`./run.ps1 '查台積電 2330' -Date '2026-10-04'`|最近可用交易日；不混入目前 MIS 快照|
|`./run.ps1 '查 9999'`|無有效日行情時 NO_DATA；不補股價|
|`./run.ps1 '台積電 2454'`|名稱代號衝突，回報輸入錯誤|

完整案例：開啟 Repo → install.ps1 → 單股指令 → 開啟 runs/ 下最新 report.md → 核對股票與日期 → 開啟 report.json 查看 issues/errors → 確認 raw/manifest.json 有來源與雜湊 → 將事實與推論分開說明。

成功的報告也可能有 PARTIAL；先解釋缺漏，再判斷哪些欄位仍可使用。19 項 mock 測試只證明特定防護，不證明外部服務全天可用。
