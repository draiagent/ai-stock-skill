使用此技能處理上市股票查詢與比較。本交付包以本地 Python 規則程式實作，不呼叫付費模型。

## 執行

本技能隨完整 `ai-stock-skill` Repo 使用；不要只複製此 SKILL.md。從本檔所在目錄向上三層可找到 Repo 根目錄，確認其中 agent.py 與 requirements.lock.txt 存在。先讀根目錄 README.md，依 Windows PowerShell 安裝流程建立環境，再於 Repo 根目錄執行下列命令。若未安裝套件或環境不相容，回報限制，不宣稱已取得行情。

```powershell
.venv/Scripts/python.exe agent.py '查台積電 2330'
.venv/Scripts/python.exe agent.py '比較台積電 2330、聯發科 2454'
.venv/Scripts/python.exe agent.py '查台積電 2330' --date 2026-10-02
```

名稱與代號矛盾時請使用者確認，不擅自選近似代號。名稱目前支援台積電、聯發科，其他股票需四碼上市代號。沒有指定日期時以 Asia/Taipei 當天為查詢日；日期一律使用 --date YYYY-MM-DD；不要把斜線日期直接放入查詢字串。範圍查詢尚不支援，不能宣稱已完成。

## 八步驟行為

1. 辨識名稱、代號、查詢日與單股／比較需求。
2. 使用 MCP `initialize` 和 `quote.realtime`，行情保留日期、時間、單位。MCP 失敗仍可查官方日資料，明示來源切換。
3. 檢查精確代號、日期、OHLC、缺值、過期與來源錯誤。無成交價不以 bid/ask、0 或其他股票補值。
4. 使用程式計算漲跌幅、振幅、MA5、MA20、全日成交量比；公式見輸出的 report.md。視窗不足、月份失敗或視窗缺值，不計算相關均線。
5. 價量判讀採相同資料口徑；MIS 的累計張數不與官方日成交股數混合。盤中不拿累計量和全日量比較。
6. 比較相同交易日，個股與大盤日期不同時顯示無法比較。分開陳述數值事實和技術推論；未還原權息，不作漲跌保證。
7. 交付 report.md、report.json、原始資料 raw/ 及 SHA-256 manifest。盤後或休市明示各來源最近實際取得交易日，不用週一至週五推定交易日。
8. 檢查錯誤、缺值與驗收結果；真實 API 與模擬失敗測試分列。API 可連線不等於資料完整，測試未執行不得標為 PASS。
